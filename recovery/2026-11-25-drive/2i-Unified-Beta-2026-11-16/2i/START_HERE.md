# Open 2i

Extract the whole ZIP before opening 2i. On Windows, double-click **Open 2i.cmd** in the 2i folder. On macOS or Linux, run `python3 2i/open_2i.py` from the extracted folder. The launcher requires Python 3.9 or later and opens 2i in your browser. Keep its terminal window open while you write.

- Use **File → Open .2i** for a native manuscript. **Save** writes a local copy and **My manuscripts** lists browser recovery copies. Use the same browser profile and launcher address to return to those copies.
- Use **File → Open Word document (.docx)** to edit formatted Word files. **Save working copy** downloads a separate DOCX. Reopen that download to continue editing. The original Word file stays intact.
- The launcher, editor, Word engine and fonts work offline. PubCast collaboration and model features depend on the Reach host or a configured model.
- Inside PubCast, open 2i from Foresight as usual. The same editor files serve the standalone launcher and the Foresight tray. Foresight's file workspace can also open rich .2i archives and retain their original Word files and working revisions separately.
