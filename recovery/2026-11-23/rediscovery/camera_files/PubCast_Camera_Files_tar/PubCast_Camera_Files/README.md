# PubCast Camera Management Files

## Overview
This directory contains the core camera management files for the PubCast AI platform.

### Key Files
- `cameras.py`: Main camera management system
- `modules/cameras.py`: Modular camera management implementation
- `main.py`: API and routing for camera management
- `audio_job_manager.py`: Supporting job tracking functionality
- `test_pubcast_control_room.py`: Camera management test suite

## Features
- Advanced camera source tracking
- Voxel Engine camera integration
- Real-time camera status management
- Flexible input source handling
