# PubCast Control Room

## Overview
PubCast is a Collaborative AI-Infused Virtual Production (CAIVP) platform that enables human-AI co-creation of films, shorts, and narrative content.

## Features
- Advanced Camera Management
- WebSocket-based Real-time Communication
- Multi-station Broadcast Control
- Voxel Engine Integration
- AI-assisted Production Workflow

## Installation

1. Clone the repository
2. Create a virtual environment
3. Install dependencies
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Running the Application
```bash
python src/main.py
```

## Testing
```bash
pytest src/tests/
```
