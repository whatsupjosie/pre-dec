## Changed

1. Tests could not run. main.js exported nothing, so 130 of 167 JS tests failed
   with "is not a function". Added module.exports (the five tested functions,
   isSafePath under the name the torture test uses, and the settings store).
2. Three torture tests called an authenticated route without the token
   (expected 200, got 401). They now send it. Note: those torture HTTP tests
   run a stand-in server written inside the test file, not main.js's server.
3. Whole-conversation capture, optional, for every user and five sites
   (Claude, ChatGPT, Gemini, Copilot, Perplexity):
   - Setting "Capture whole conversations", OFF by default, plus a per-site
     toggle (settings window). Stored keys: captureConversations,
     conversationSites; validated in SETTINGS_SCHEMA.
   - extension/conversation_scraper.js: one reader for all sites; each site is
     one row of page selectors. Reads nothing unless the app says on for that
     site. Captures after the chat goes quiet for 3 s (every turn, not every
     fifth), and on tab close.
   - Server: GET /conversation-capture (the switch, auth-checked);
     POST /collect-conversation refuses (403) when off for that site, and now
     saves the full transcript as <primaryDir>/conversations/<site>/<id>.json
     and .txt, rewritten in place (atomic) as the chat grows. Before this the
     app kept only a short summary.
4. Moved, not deleted: extension/claude_scraper.js (Claude-only, always on)
   and Thinking_Context_Collector/ (PubCast Jeremy Cricket code) are in
   _moved_out/.
